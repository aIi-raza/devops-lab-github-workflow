# Dataset

The actual dataset files (`KDDTrain+.txt` and `KDDTest+.txt`) are **not included** in this
repository due to their size. Download them from one of the sources below and place them
in this `data/` folder before running `main.py`.

**Official source:**
https://www.unb.ca/cic/datasets/nsl.html

**Kaggle mirror:**
https://www.kaggle.com/datasets/hassan06/nslkdd

After downloading, this folder should contain:
```
data/
├── KDDTrain+.txt
└── KDDTest+.txt
```
