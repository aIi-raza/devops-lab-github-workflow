What the data looks like

NSL-KDD, a standard benchmark for network intrusion detection.

Each row is one network connection described by 41 measurements: how long it lasted, which protocol and service it used, how many bytes moved each way, how many errors occurred, and so on. The dataset has {{ fmtInt(total) }} rows, 125,973 from the official training file and 22,544 from the official test file.

Attack families in the data

DoS
Floods a server with requests until it stops responding.
Probe
Scans a network to find weak spots before attacking.
R2L
An outsider tries to get access to a machine, for example by guessing passwords.
U2R
A normal user tries to gain administrator rights.

This project treats all four as a single class: attack.

Where the paper’s test falls short

The paper reports one random split of the merged data. We tested two things it did not.

First, we repeated the test five times on different parts of the data (5-fold cross-validation). Second, we trained on the official training file and tested on the official test file, which contains attack types the training file never shows.
